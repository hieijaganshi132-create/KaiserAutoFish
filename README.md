# Kaiser AutoFish — Fabric 1.20.1

Mod de cliente para Minecraft Java 1.20.1 / Fabric.

- F6 liga/desliga.
- Indicador no HUD.
- Detecta a variável interna `caughtFish` da boia por Mixin Accessor.
- Recolhe a captura e tenta lançar novamente.
- Aceita vara na mão principal ou secundária.
- Desliga se a vara estiver prestes a quebrar.

## Requisitos
Minecraft Java 1.20.1, Fabric Loader, Fabric API para 1.20.1 e Java 17.

O arquivo compilado será publicado automaticamente na aba **Actions** como artefato `KaiserAutoFish-1.20.1`.
